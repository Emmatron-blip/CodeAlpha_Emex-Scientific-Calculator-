# CodeAlpha_Emex-Scientific-Calculator-# CodeAlpha Calculator

A responsive, web-based calculator built with HTML, CSS, and JavaScript. The project provides a clean user interface and interactive mathematical calculations.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division.
- Interactive calculator interface.
- Calculation history.
- Clear history functionality.
- Responsive design for different screen sizes.
- Simple and user-friendly interface.

## Technologies Used

- HTML5 — Structures the calculator interface.
- CSS3 — Provides styling and responsive layout.
- JavaScript — Handles calculations, user interactions, and calculation history.
